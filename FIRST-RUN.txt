BLUE PRINCE VR - FULL PACKAGE 0.1.96 - OCTOBER 25, 2026

This is Windows PC VR, not a standalone Quest game. You need Blue Prince,
SteamVR, motion controllers and a headset connected to your PC.

EXE OR MANUAL, NOT BOTH
Extract the outer package. The Setup EXE is the guided option with
backups/restore and an optional developer checkbox. Select the actual
folder containing BLUE PRINCE.exe, GameAssembly.dll and BLUE PRINCE_Data.
Close the game before installing/updating/restoring.

For manual setup, extract the Manual ZIP. Copy the contents of GameFiles
into the game folder, including the root DLLs, not just Mods.
Defaults-Only contains fresh-install seeds. Existing users should copy
ONLY missing seed files, not replace preferences/calibration.
Optional-Developer is separate. Do not copy another person's UserData.

The Source ZIP is for building/development, not an installation method.

DEPENDENCIES
The official x64 MelonLoader 0.7.3 files are included. Setup can download
and verify missing Microsoft runtimes. Manual users need:

.NET 6 Windows Desktop Runtime x64:
https://dotnet.microsoft.com/en-us/download/dotnet/6.0
Microsoft Visual C++ x64 runtime:
https://aka.ms/vs/17/release/vc_redist.x64.exe

Use the .NET 6 x64 Desktop Runtime, not just a different .NET major.
This legacy mod targets .NET 6; this is not a Microsoft support claim.
Microsoft runtime installers aren't included in the Manual ZIP.

Connect headset, start SteamVR, then launch through Steam. First launch
may need internet and several minutes for binding generation. Let it finish.
Setup is unsigned; verify source/checksum before deciding to run it.

UPDATING
Setup preserves personal data and calibration, merges missing VR defaults,
and restores the normal intro setting. Restore refuses to overwrite files
edited after installation. Keep its backup folder. Manual copies have no
automatic rollback: back up your installation/save first.

The runtime here is the CPU-verified 0.1.96, including the cart release and
boat fixes, held blueprint, graphics choices and menu-search optimization.
The failed experimental render-thread submission/closed-panel budgeting
paths are disabled/ignored, even if an older config requests them.
No forced headset refresh, Spacewarp or Windows power setting change.

Developer mode is OFF by default in Setup. F/I room/item pickers work when
selected, with their front bars hidden by default. Use a separate save.
Leaving it off doesn't remove a developer mod you already installed.

Pump/Boiler/Utility physical input can be disabled individually with
PhysicalPumpControls, PhysicalBoilerControls, PhysicalUtilityControls in
UserData\BluePrinceVR-Backpack.cfg after first launch, retaining legacy
controls for troubleshooting. Fresh installs have grip screenshots off.

No ROMs, emulator core, native saves, personal captures, recordings, notes,
extracted game assets, game binaries or generated bindings are shipped.
All current mod models/bundles, feedback audio and the offline voice model
are included. Read README.txt/README.md, CONTROLS.txt and the notices.

This is experimental. The newest boat/cart interactions need more headset
feedback, and CPU checks don't promise native 90 FPS or every-room testing.
